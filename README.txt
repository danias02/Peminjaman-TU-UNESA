WEBSITE PEMINJAMAN BARANG TU UNESA

Cara menjalankan:
1. Ekstrak folder Pemweb jika dari ZIP.
2. Buka index.html di browser (Chrome/Edge disarankan).
3. Navigasi Beranda, Daftar Barang, Form peminjaman, dan Cek Status tersedia di bagian atas.

File:
- index.html : struktur halaman
- style.css  : desain dan responsivitas
- script.js  : pencarian barang, isi form, nomor permohonan, cek status
- assets/    : aset gambar yang diekstrak dari PDF desain

Catatan:
Data permohonan berjalan di browser saat halaman masih terbuka, belum tersimpan ke database/server. Desain direkonstruksi dari PDF Figma yang diberikan; hasil bisa memiliki perbedaan kecil dibanding Figma asli karena PDF tidak menyediakan semua spesifikasi ukuran, font, dan perilaku prototipe.
